DEPLOYMENT
Upload the contents of this folder directly to the root of your GitHub repository.
All HTML pages, including index.html, are in the root. The shared stylesheet is in assets/.
There is no pages/ subfolder and no numbered HTML filenames.
Before deployment, replace YOUR-GITHUB-PAGES-DOMAIN in sitemap.xml and robots.txt with your actual GitHub Pages URL.
The homepage links to every topic page. Topic pages link to related topics and previous/next topics.
Topic filenames are keyword-based and unique.
